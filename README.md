# MiCar PDI

小米汽车交付检查工具，本版本只包含 **小米澎程 N70 Pro 与 N70 Max**，不包含 N90、SU7 或 YU7。保留 121 项通用检查，Pro 增加 17 项专项检查（共 138 项），Max 增加 18 项（共 139 项，含空气悬架）。没有 TypeScript、npm、打包器或后端。

首次打开先选择交付版本，之后恢复该版本的清单、结果、备注与照片。更换版本会要求确认，再清空当前记录与照片并开始新一次验车；取消不会改变数据。旧版记录没有车型标识时会要求选择，不根据备注猜测版本，首次关联保留原有记录。请确认旧记录属于所选 N70。

N70 配置依据用户提供的 21 页参数配置表，核对日期为 2026-10-09，对应官网参数页的 N70 标签。实际年款、选装与 OTA 状态仍须对照订单及交付说明；未安装的选装项可记不适用，不自动标记检查结果。

## 使用与发布

适用于支持所需 Web 功能的现代手机和桌面浏览器，包括 Chrome、Edge、Safari、Firefox；并非仅限 iPhone。需要启用 JavaScript，允许 IndexedDB 本机存储，并支持 Canvas、原生 dialog 等 API。建议使用近期版本，通过 HTTPS 地址使用；具体安装、相机、图片解码与文件分享能力因浏览器及设备而异。

可直接打开 `index.html` 预览；本地文件模式的存储行为因浏览器而异，可靠保存与离线使用建议部署至 HTTPS 或 localhost。经典脚本按依赖顺序加载，无需构建或 ES module 加载器。PDF 库从 jsDelivr 加载；本地文件模式导出 PDF 还需联网获取中文字体。

GitHub Pages 使用 GitHub Actions 发布，无需构建或安装依赖：

1. 把本目录推送到 GitHub 仓库。
2. **Settings → Pages → Source** 选择 **GitHub Actions**。
3. 推送到 `main` 自动发布，或在 Actions 中手动运行 **Deploy static site to GitHub Pages**。默认分支不同时，修改工作流的触发分支。
4. 在手机或电脑的支持浏览器中打开 Pages 的 HTTPS 地址，即可使用。

安装为应用是可选项，不是使用前提：

- Android：支持安装的浏览器菜单中选择“安装应用”或“添加到主屏幕”。
- iPhone / iPad：Safari 分享菜单中选择“添加到主屏幕”。
- 电脑：支持安装的浏览器通常在地址栏或菜单中提供安装入口。

菜单名称与安装支持因浏览器而异；没有安装入口也可直接在浏览器使用。首次联网打开并等待“离线内容已就绪”，之后才能可靠离线使用。

全部路径为相对路径，支持仓库子路径或自定义域名。当前 `.github/workflows/static.yml` 直接上传仓库并发布，不运行 npm 或构建，也不自动运行测试。发布前请自行运行 `node tests/check.mjs`。

## 保存与离线

使用原生 IndexedDB 保存当前一次验车。等“已保存至本机”后，刷新、关闭重开会恢复状态、备注、车辆信息与照片。备注每次输入立即提交保存队列，失败可重试；强制关闭时尚未提交的输入不能保证保存。

沿用之前版本的数据库名和记录格式；同一来源的旧记录不会被本次重构主动清除。本机存储仍不是永久备份：清除网站数据、无痕模式、设备回收存储或换域名、设备和浏览器可能丢失记录。不同浏览器、用户配置与已安装应用可能使用不同数据空间，请保持使用同一入口，结束后保存 PDF。

照片为长边最多 2560 像素、质量 0.85 的 JPEG 副本，不保留原片。请放大确认文字清晰；不能解码的 HEIC 会提示转换或重新拍摄。

PWA 需要 HTTPS 或 localhost，直接打开本地 HTML 不启用离线缓存。首次联网时，`sw.js` 缓存 HTML、全部本地脚本、图标、中文字体和固定版本的 jsDelivr 库。等“离线内容已就绪”后才能可靠离线使用和导出；CDN 无法访问时离线安装不能完成，但记录功能仍可使用。

更新内容时，把 `sw.js` 的缓存版本 `v1` 改成 `v2` 等新版本，连同文件一起发布。用户可在新版本提示中选择保存后更新。缓存按应用路径隔离，不删除验车数据库。

## PDF

进入“验车报告”生成，完成后分享或下载。支持文件分享的手机或桌面浏览器可调用系统分享；不支持时使用“下载 PDF”保存报告。报告包含选定车型、车辆信息、异常摘要、121 项通用与该版本专项检查结果、备注和照片附录，内嵌中文字体，不依赖系统打印或服务器。进度与报告不计入其他版本的检查项或照片。

PDF 为存档，不能导回编辑。生成时暂时禁止修改以保证一致性；大量照片会增加内存和耗时，失败不会删除本机记录。清空重验有二次确认，请先保存报告。

## 文件与检查

- `index.html`：页面入口、样式与脚本加载顺序。
- `data/common.js`：121 项通用检查与原有稳定 ID。
- `data/models/n70.js`：N70 Pro / Max 配置、来源、专项检查及通用项目补充。
- `data/catalog.js`：通用车型注册与清单组合，不包含车型专属判断。
- `app.js`：车型选择、页面渲染、IndexedDB、照片与 PDF 逻辑。
- `sw.js`、`manifest.webmanifest`、`.nojekyll`：PWA 与静态发布。
- `public/icons/`：应用图标。
- `public/fonts/`：中文字体及许可证。
- `tests/check.mjs`：可选无依赖检查，用已有 Node 运行 `node tests/check.mjs`。
- `.github/workflows/static.yml`：GitHub Pages 发布。

测试覆盖通用 ID、N70 版本差异、清单隔离、PDF 内容、车型切换与离线文件清单。无需安装测试框架或下载 Chrome。

## 新增车型

在 `data/models/` 增加独立的家族脚本，向 `globalThis.MiCarFamilies` 注册对象：

```js
(globalThis.MiCarFamilies ??= []).push({
  id: "family-id",
  name: "家族名称",
  source: { url: "官方配置来源", checkedAt: "YYYY-MM-DD" },
  models: [
    {
      id: "family-trim",
      name: "版本名称",
      summary: "主要配置",
      detail: "版本差异",
    },
  ],
  overridesFor(model) {
    return {};
  },
  categoriesFor(model) {
    return [];
  },
});
```

`overridesFor` 按通用项目 ID 返回 `title`、`check`、`howTo` 替换内容或 `appendHowTo` 补充；`categoriesFor` 返回该版本的专项分类，每项有 `id`、`title`、`check`、`howTo`。模型配置和条件判断只放在对应家族文件，不放在 UI 或通用注册器。

新脚本放在 HTML 的 `common.js` 之后、`catalog.js` 之前，并加入 `sw.js` 缓存和测试加载列表。车型 ID 全局唯一，专项分类与项目 ID 使用家族前缀；跨版本共用同一含义的项目可复用 ID。已有通用条目的顺序决定历史 ID，请勿插入、重排或重新编号。更新后提升缓存版本并测试版本差异、保存恢复及报告内容。

Android、iPhone / iPad 与桌面浏览器的拍照或文件选择、图片解码（包括 HEIC）、分享或下载、可选安装和离线行为仍需在目标设备上线后验证，不能保证所有浏览器拥有相同能力。本地文件预览不能替代 HTTPS 环境的 PWA 验证。

## 说明与安全

保持车辆静止，不拆盖板、不碰高压部件、不钻车底，不用身体测试防夹。需要挂挡、充电或举升检查请工作人员协助。

玻璃日期编码因厂家而异，不套用通用点数公式。轮胎常见四位码 `2326` 表示 2026 年第 23 周。轻微浮锈、空调冷凝水或不同玻璃生产日期不能单独证明车辆异常。

本清单及 PDF 是个人交付记录，不构成专业检测或车辆合格证明。默认不上传记录与照片；CDN 请求只加载公共库与字体。

中文字体为 Noto Sans CJK SC，遵循随字体分发的 SIL Open Font License。UI 图标使用 Lucide，PDF 使用 pdfmake；两者均从固定版本 jsDelivr 地址加载。

本工具为个人验车记录工具，并非小米官方应用。
