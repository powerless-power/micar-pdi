# MiCar PDI

非官方小米汽车交付检查工具，帮助车主在提车时逐项检查车辆、记录问题并生成 PDF 验车报告。

**在线使用：** [MiCar PDI](https://powerless-power.github.io/micar-pdi/)

## 支持车型

- **SU7：** SU7、Pro、Max
- **SU7 Ultra：** 普通版、纽北限量版（2025版）
- **YU7：** 标准版、长续航版、Pro、Max、GT
- **N70：** Pro、Max
- **N90：** Max、探索版

## 使用方法

1. 选择车型及具体版本。
2. 按检查清单逐项检查，记录结果、备注和照片。
3. 完成后生成 PDF 验车报告，保存或分享。

更换车型前，请先导出当前报告。确认更换后，当前验车记录与照片将被清空。

## 数据与隐私

- 检查记录和照片保存在当前设备的浏览器本地，不上传至服务器。
- 清除网站数据、更换浏览器或设备可能导致记录丢失，请及时导出 PDF 备份。
- 照片以压缩后的 JPEG 副本保存，不保留原始文件。
- 首次联网打开并等待离线资源加载完成后，才可可靠地离线使用。

## 本地运行与部署

无需安装依赖或构建。可直接打开 `index.html` 预览；推荐通过 HTTPS 或 `localhost` 使用，以确保本地存储和离线功能正常工作。

如需部署到 GitHub Pages：

1. 将代码推送到 GitHub 仓库。
2. 在仓库 Settings → Pages 中选择 GitHub Actions。
3. 推送到 `main` 分支触发部署。

## 安全说明

- 检查时保持车辆静止，不拆卸盖板、不触碰高压部件、不钻入车底。
- 需要挂挡、充电或举升车辆时，请由工作人员协助。
- 本工具仅用于个人交付检查与记录，不构成专业检测或车辆合格证明。

本项目为个人开发的非官方工具，与小米汽车无官方关联。
